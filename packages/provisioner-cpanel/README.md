# @provisia/provisioner-cpanel

Provisioner module for **cPanel / WHM** using WHM API 1 over HTTPS (port 2087) with API-token
authentication. Module id: `cpanel`.

## What it does

| Provisia action | WHM API 1 call |
|---|---|
| create | `createacct` (+ `setacls` when `reseller` and `aclList` are set) |
| suspend / unsuspend | `suspendacct` / `unsuspendacct` |
| terminate | `removeacct` (`keepdns` from product config) |
| changePackage | `changepackage` |
| changePassword | `passwd` |
| getUsage | `accountsummary` (disk) + `showbw` (bandwidth) |
| loginUrl | `create_user_session` (`cpaneld` by default) |
| testConnection | `version` |
| listRemoteOptions(`packages`) | `listpkgs` |

## Server credentials (encrypted at rest)

```json
{ "username": "root", "apiToken": "..." }
```

Create the token in WHM: **Home » Development » Manage API Tokens » Generate Token**.
Required privileges (ACLs) when the token belongs to a reseller or is restricted:
`create-acct`, `suspend-acct`, `kill-acct`, `upgrade-account` (changepackage), `passwd`,
`show-bandwidth`, `list-accts`, `list-pkgs`, `acct-summary`, `create-user-session`, and
`basic-system-info` for `version`. For reseller products add `allow-addoncreate` and `acl` access.

Server fields: hostname (WHM host), port (default 2087), secure (HTTPS, default on). cPanel uses a
self-signed certificate on fresh installs; install a valid certificate (AutoSSL) because the worker
does not disable TLS verification.

## Product config (`products.module_config`)

```json
{ "package": "starter", "reseller": false, "aclList": "", "loginService": "cpaneld", "keepDns": false }
```

`package` must be a WHM package name visible to the token's user (discover via
`GET /api/v1/admin/servers/:id/options/packages`).

## Notes

- Usernames are derived from the domain (max 8 chars, no leading digit) unless the service already has one.
- Passwords are generated by the worker when the service has none and stored encrypted.
- `loginUrl` returns a one-time session URL that expires after a few minutes; do not cache it.

## Testing

Unit tests mock HTTP (`src/test-utils.ts`), no live server needed: `pnpm --filter @provisia/provisioner-cpanel test`.
For a manual run, a cPanel trial license on a VM works; point a server at it with a root API token and use
"Test connection" in the admin.
